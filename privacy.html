Privacy policy

Peti álláskereső is a private tool used by a single person, the owner of the connected Gmail account.

What it accesses

With the owner's permission it uses the Gmail API to send job applications and follow-up emails the owner has approved, and to read incoming messages so replies from employers can be matched to applications.

What it does with the data

Email content is used only to run the owner's own job search. It is not sold, shared with third parties, used for advertising, or used to train AI models. Nothing is collected from anyone other than the account owner and the employers they correspond with.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com → Security → Third-party connections.
